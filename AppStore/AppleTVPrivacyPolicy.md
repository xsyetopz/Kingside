# CHESS Privacy Policy

CHESS is designed to keep local play local.

## Information stored on Apple TV

CHESS stores game progress, recent games, puzzle progress, and application preferences on the Apple TV so games can be resumed. This information is not uploaded to the developer and can be removed by deleting the application.

## Network features

Local games and bundled puzzles work without an internet connection. If a user chooses the Players feature, the public username they enter is sent directly to the documented Chess.com public API to retrieve public profile and game information. CHESS does not request, receive, or store Chess.com passwords or authentication credentials. Chess.com processes those requests under its own privacy policy.

## Tracking and advertising

CHESS does not include advertising, behavioral tracking, or third-party analytics SDKs. It does not sell personal information.
